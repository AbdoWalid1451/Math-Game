# 🎮 Math Game

A console-based math game built using C++.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Multiple difficulty levels
- Random question generation
- Score tracking system

## 🛠️ Technologies
- C++
- Console Application
- Fuctional Programming (without OOP)
