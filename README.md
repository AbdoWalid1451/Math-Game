# 🎮 Math Game

A console-based math game built using C++.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Multiple difficulty levels
- Random question generation
- Score tracking system

## 🛠️ Technologies
- C++
- Console Application
- OOP Concepts

## 🚀 How to Run
1. Open the solution file in Visual Studio
2. Build the project
3. Run the application
